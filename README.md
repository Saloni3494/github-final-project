# Paradise Nursery

Paradise Nursery is an online web application for purchasing houseplants. This project is built using React and Redux.

## Features
- Browse multiple categories of houseplants.
- View plant details including name, price, and thumbnail.
- Add items to your shopping cart.
- Adjust quantities and view total costs in the cart.

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Router DOM
- CSS

## How to Run Locally
1. Clone the repository.
2. Run `npm install` to install the dependencies.
3. Run `npm run dev` to start the development server.
